HOW IT WORKS

Built for reproducibility

Follow the process from your Ubuntu terminal to a website served from AWS.

01

Write infrastructure code

Create the VPC, subnet layout, security rules and EC2 resources from Terraform files.

terraform plan
02

Provision AWS resources

Review and apply the changes, then obtain the Application Load Balancer DNS.

terraform apply
03

Configure your servers

Use Ansible's dynamic inventory to install Apache and deploy these website files.

ansible-playbook
04

Publish the website

Open the load balancer URL, verify HTTP response and confirm the target health.

HTTP 200 = served

How the pieces connect

Terraform creates a VPC, two public subnets in different Availability Zones, an Application Load Balancer and an Auto Scaling Group. The initial group launches two Linux web servers.

Ansible identifies the EC2 instances by their AWS tags, connects to each server over SSH, installs Apache and copies this website into /var/www/html/.

The load balancer routes browser requests to the healthy instances. Newly launched replacement servers must also receive the configuration through a separate automated bootstrap process.
